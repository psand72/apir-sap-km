# Base de Connaissances SAP

Bienvenue dans la base de capitalisation SAP ! Cette documentation centralise les connaissances, bonnes pratiques et exemples pour les projets SAP Datasphere, BW et S/4HANA.

## 🎯 Objectif

Cette base de connaissances vise à :

- Documenter les architectures et patterns techniques
- Capitaliser sur les projets réalisés
- Faciliter les migrations et intégrations
- Partager les bonnes pratiques SQL et transformations
- Accélérer la montée en compétence sur les nouveaux projets

## 📚 Contenu

### [SAP Datasphere](datasphere/index.md)
Configuration, modèles analytiques, dataflows et CDS views pour SAP Datasphere.

### [SAP BW](bw/index.md)
Documentation des structures BW, transformations et migrations vers Datasphere.

### [SAP S/4HANA](s4hana/index.md)
Modules (MM, PP, SD, COPA), tables clés et stratégies d'extraction.

### [SQL & Transformations](sql/index.md)
Patterns SQL, conversions ABAP, optimisations et exemples concrets.

### [Projets](projets/index.md)
Documentation des projets clients avec contexte, architecture et solutions techniques.
